# Omnidle

A daily pop-culture guessing platform across **Video Games, Anime, Cinema and Music**: four independent daily challenges of ten mini-games each, plus endless free play.

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # typecheck + production build
npm run data:validate  # schema + coverage check for the dataset
```

Stack: Vite · React 18 · TypeScript · Tailwind CSS v4 · Zustand (persisted to `localStorage`) · React Router (hash routing) · canvas-confetti. Deployed to GitHub Pages by `.github/workflows/deploy.yml`.

## Daily mode

Each category has its own challenge at `/daily/<games|anime|cinema|music>[/YYYY-MM-DD]`. `buildDaily(date, domain)` in `src/lib/rounds.ts` seeds a PRNG with a hash of `omnidle:<date>:<domain>`, so every player gets the same ten rounds — ten different mechanics, one each, with no repeated target (Anime and Video Games have eleven mechanics with the voice game, so one sits out each day). Answers don't repeat across days either: each day replays the dailies since `EPOCH` (cached) to know when every work, puzzle and timeline entry last came up, and `leastRecent()` picks among the ones never used, then the ones used longest ago. Specialist dailies do the same. Free Play, Specialist practice and boss fights keep a saved history (`seen` in the store, most recent first) and draw what hasn't come up lately. Works that have real media (cover, item/location image, YouTube clip) are drawn four times as often for the rounds that use them.

Progress is stored per `domain:date` (`src/store/progress.ts`). Each round is a `RoundRecord` (`status`, `guesses`, `score`) and games rebuild their whole view from `guesses`, so half-played rounds resume exactly. Streaks are tracked per category, plus an overall streak (any category completed that day). The archive lists every past day per category since `EPOCH`.

## Mini-games

| Game | Component | Media |
|------|-----------|-------|
| Classic attributes | `ClassicGame` | Green / yellow (partial) / red; shared genres and platforms are ticked, a year within 3 is yellow, ▲▼ for year. Cinema adds Type (live-action / animated), anime adds Creator. Clues unlock after 3, 5 and 7 misses: themes (or, without themes, a side character or track), a credit line, then a side character (albums: a track); any that names the title is skipped |
| Quote | `ClueGame` | Quote with progressive hints; albums reveal their **tracklist** instead |
| Soundtrack | `ClueGame` + `AudioClip` | Hidden YouTube player, Heardle-style 1→16 s snippets starting ~40% into the clip (or `audio.start`); video revealed at the end. If a clip is missing or won't play, the round becomes a **zoomed-in cover detail** (`ZoomImage`), then text |
| Voice Line | `ClueGame` + `AudioClip` | A character's original voice acting (no openings, endings or soundtrack), 2→16 s snippets from `voice.start`; the speaker is the last hint. Anime clips are in the original Japanese; when none is found, the French dub (marked **VF**, `voice.lang: "fr"`), never an English dub. `node scripts/find-voice-clips.mjs` searches YouTube for anime without a clip (titles only, so picks are worth a listen). Anime and Video Games only |
| Emoji | `ClueGame` | One more emoji per miss |
| Pixelated | `ClueGame` + `PixelCanvas` | Real cover art (or a generated glyph cover), de-pixelates per miss |
| Timeline | `TimelineGame` | Drag or arrows, 3 attempts |
| Guess from the Image | `ClueGame` + `ObscuredImage` | Picture of an iconic item, partly shown through clear windows (colour-shifted, tilted) that open further with each miss; the description becomes the first hint |
| Location | `ClueGame` + `ZoomImage` | In-world screenshot or real filming/recording location, starting at ×3.2 on a focal point (`location.focus`) and zooming out per miss |
| Cover Puzzle | `TilesGame` + `TilePuzzle` | The cover cut into a 3×3 grid, shuffled, rotated and disguised per tile (colour shift, blur, some inverted or mirrored). Swapping (tap two) and rotating (tap one twice) help read it, but only typing the title wins; a piece keeps its disguise wherever it's moved, and each miss restores two pieces to their true look |
| Connections | `ConnectionsGame` | 16 picture tiles in 4 groups of 4, Yellow→Purple difficulty, 4 mistakes, "One away…" |

`GameHost` adds the shared juice: synthesized WebAudio SFX (`src/lib/sfx.ts`; the 🔊 header button opens a panel to switch them off and set two saved volumes — effects, and clips & voices for the YouTube soundtracks, voice lines and laughs), confetti (`src/lib/fx.ts`), a glow on wins and slide-in round transitions. Finishing a daily plays a fanfare and produces a Wordle-style share text:

```
Omnidle Video Games 2026-10-18 — 820/1000 🔥3
🟩🟩🟨🟥🟩
🟩🟨🟩🟩🟥
```

## Data

- **Works**: `src/data/works/{games,anime,cinema,music}.json`, 100+ per category. Shape: [`schema/work.schema.json`](schema/work.schema.json). Optional fields (`quote`/`tracks`, `audio`, `emoji`, `item`, `location`, `cover`, `visual`) decide which mini-games a work can appear in.
- **Connections**: `src/data/connections.json` (10 per category + 7 mixed) — `domain` decides which daily uses a puzzle (`mixed` = free play), `theme` marks single-universe grids, each group has a `level` 0–3. A tile is a label or `{ "label", "src" }`; `images` sets the puzzle's default picture source (`wp`, `fandom:<wiki>`, `ddragon`). `node scripts/enrich-connections.mjs` resolves them and reports misses — a grid only shows pictures when all 16 tiles have one, since a lone text tile would give its group away.
- **Themed Connections**: `src/data/connection-themes.json` — per theme (One Piece, Zelda, Star Wars...), a list of `cards` and reusable `categories` (`{ id, label, level, items }`). Six grids in ten are built at play time from four of a theme's sub-categories, four tiles each (`settings.json` → `connections.themed`) (`src/lib/connections.ts`, id `theme:<theme>:<seed>`): no tile on a board fits two of its groups (a card listed in several of the board's sub-categories stays off it, so there are never five Fire types for four slots — which needs complete memberships in the data), and boards avoid a lone group of places or objects among characters (`kind` per sub-category, read from the label when left out: "Islands…" is places, "Link's tools" things); when a theme can't avoid one, that group is coloured as the easiest. Sub-categories sharing no card at all in the theme are preferred, and every grid is checked to have exactly one solution. Trio sub-categories (the Legendary Sannin, the Triforce bearers, the Golden Trio) stack extra layers on one franchise. Add a sub-category by listing its cards; `enrich-connections.mjs` fetches the new pictures.

- **Boss Battle**: `src/data/bosses.json` — one guardian per franchise with dialogue, Knowledge Blitz prompts (`"Name|alias|alias"` answers), Radar `members`/`impostors` and Final Blow cards. Cards use the same picture sources as Connections tiles; `node scripts/enrich-bosses.mjs` resolves them. Easy, Medium and Hard (`DIFFICULTIES` in `src/lib/boss.ts`) set the rounds per phase, timers, wave sizes and visual distortion; validation requires pools big enough for Hard (6+ prompts, 12+ members, 10+ impostors, 12+ faces). The numbers live in [`src/data/difficulties.json`](src/data/difficulties.json). `rounds` lists the rounds per phase: Easy plays the first three phases once; Medium and Hard add a fourth, the **Name Chain** (`chain` settings): the boss names something of one category ("Character: Zoro"), the player answers with a different one of the same category, nothing can be named twice, and a wrong category, a repeat or a timeout loses the round (a heart). There are no suggestions and no list of what was already named. Settings: `picksToWin`, `turnSeconds`, `bonus`. Knowledge Blitz answers count only when Enter is pressed. A `secondLoop` block can still make a phase's second round harder, but none uses it now. Emptying the life bar on **Hard** starts the secret **Signature** (`signature` settings: `toWin`, `chances`, `seconds`, `bonus`): one clue on a very specific side of the franchise, no suggestions — a right answer wins; a wrong one or a timeout takes every heart and brings one last chance on a new clue — One Piece laughs (clips), League items by their stats and price (Data Dragon), Genshin constellations, MCU actors, World of Warcraft raids (name the final boss), Overwatch ultimates, Minecraft mob drops, Dragon Ball and Naruto techniques, Star Wars ships, Patronuses, Middle-earth weapons, Final Smashes and Inazuma Eleven hissatsu. Clues live in each boss's `signature` block, written by `node scripts/data/boss-signatures.mjs`. Each boss lists its categories in `bosses.json` (`secret.categories`, entities as `"Name|alias"`) and can override the settings there; `picksToWin` is capped at what the categories allow (floor(n / 2) per category).
- **2D art only in Boss Battle**: 3D models are for silhouettes (Who's That?). `node scripts/data/boss-2d-art.mjs` gives the Overwatch, Smash and Minecraft bosses drawn pictures — Overwatch's "Cute" sprays (Valorant's painted agents as impostors), Smash's fighters in their original series' art or sprites (picked by eye, `scripts/data/boss-2d-art.json`), Minecraft's pixel faces and textures (served from `public/art/minecraft`, as minecraft.wiki blocks other sites) — and marks them `drawnOnly`, so Final Blow takes no card pictures for them (`src/boss/faces.ts`). Faces with no 2D art sit out (`finaleSkip`, `radarSkip`) but keep their cards; every card keeps the picture it was pulled with (`src/data/card-art.json`). Minecraft's pictures are drawn without smoothing (`pixelArt`). For Honor and Destiny have no drawn art on their wikis yet.
- **JLPT boss** (Boss Battle, Other): Oni-Sensei, keeper of the kanji, written by `node scripts/data/jlpt-boss.mjs` from `src/data/jlpt.json`. Its cards are kanji drawn in the browser (`"image": "kanji:山"`, `src/lib/kanji.ts`: ink on squared paper, the guardian a red seal), named by their meaning, with the other meanings and the readings (romaji and kana) as aliases — typed answers keep kana and kanji (`normalizeText`). Radar: the kanji Japan kept against their simplified Chinese twins (門 / 门); Final Blow: N5 and N4 kanji; Name Chain: animals, food, places, verbs and adjectives in romaji; Signature: N3 kanji. The same script writes `src/data/jlpt-cards.json`, so the JLPT card set holds a card for every kanji of the list (2,215 with the boss's, its mythics and its omni, 日本語, which wakes as 漢字 after a Hard win), each saying its meanings, readings and level; a kanji whose meaning another card already has goes by another of its meanings, else by its meaning and reading ("Kanji (ka)"), so card ids stay unique.
- **French names**: works can carry `nameFr` (the French release title) and boss answers list French spellings as aliases. Both live in `scripts/data/` and are applied by `node scripts/add-french-titles.mjs`. The Inazuma Eleven boss goes further: `node scripts/data/inazuma-french.mjs` makes the French dub names (Mark Evans, Main Magique, Tempête des Gémeaux, Ray Dark…, checked on the French wiki) the displayed names, keeping the Japanese and English ones as accepted answers.
- **Batches of works**: `scripts/data/new-anime.mjs` and `new-games.mjs` hold the latest 100 entries in compact form; `node scripts/add-works.mjs` merges them and gives anime and voiced games a `voice` entry (speaker + search query), then `enrich-media.mjs` fetches pictures.
- **Who's That?** (`/whos-that`): name blacked-out silhouettes one after another until the first mistake — a wrong name or a pass ends the run, and the score is the streak. The results show the silhouette that ended it and what was typed. **Easy** keeps the plain silhouette; **Rising** gets harder every 4 names (turned, then zoomed in on part of it, maybe mirrored, cropped, and finally spinning); **Hell** gives 10 seconds per silhouette (running out ends the run) and cycles one effect per silhouette — normal, turned, zoomed, mirrored, cropped, spinning, then normal again. **Flash** shows the plain silhouette for 1.5 s once its picture has loaded, then hides it; every name shortens the glimpse (geometrically) down to 0.2 s at a 50 streak, where it stays. Crops cut the same slice off two opposite sides and sit outside the turn and spin, so their edges stay straight. Best streaks are kept per mode. Play one series or "All" of a domain. English and French names both count (French names are aliases; names that are the same in French have none). Rosters live in `src/data/silhouettes.json`, built by `node scripts/build-silhouettes.mjs` (League of Legends renders, Minecraft mob renders, Pokémon official artwork with French names, World of Warcraft renders from the Specialist data, One Piece renders from Thousand Storm, with World Seeker, Burning Will and Unlimited World Red as fallbacks — never Bounty Rush, whose glow outline shows as a doubled edge, nor Pirate Warriors, whose renders sit on brush strokes). Only cut-outs with a transparent background work as silhouettes: pictures are checked in the browser (share of transparent pixels, and gaps around the shape) and the choices applied with `--apply=choices.json`.
- **Specialist** (`/specialist`): one universe per page, with a daily (the same rounds for everyone, one of each type, seeded by date, streak and share text) and endless practice. Every universe ends with a **Timeline**: five characters to put in the order they first appeared — debut chapter for One Piece (at least 20 chapters apart), release year for League, debut film for Marvel, release version for Genshin and first game for World of Warcraft (hand-written in `scripts/data/wow-debuts.mjs`); four tries, each showing which places are right, and the debuts revealed at the end (`src/specialist/timeline.ts`, `games/TimelineRound.tsx`). Timeline rounds are left out of the daily no-repeat history, so the days before it was added keep their rounds. One Piece, League of Legends, Marvel (MCU), Genshin Impact and World of Warcraft are all playable. Each universe lists its round types in `UNIVERSES` (`src/specialist/rounds.ts`). One Piece rounds: **Classic** (gender, affiliation, Devil Fruit type, Haki, bounty ▲▼, height ▲▼, origin, first arc ▲▼; close numbers and neighbouring arcs are yellow), **Devil Fruit** (the fruit's picture when it has been shown, opening per miss; hints from its type, name meaning, debut arc, English name and user; naming a character costs a try, and if it's the fruit's user it shows a shortlist of 8 fruits, same type first), **Laugh** (a character's signature laugh in the original Japanese voice, in 1 → 12 s snippets; the written laugh is a late hint, and the clue itself if a clip can't play — clips found by `node scripts/find-laugh-clips.mjs`, titles only, with a reject list for checked mismatches), **Jolly Roger** (the crew's flag) and **Wanted** (the character's wiki portrait on a wanted poster, blurred and in black and white, sharpening with each miss; its colours come back after three misses, as a hint). Data: `src/data/specialist/onepiece.json`, built by `node scripts/build-specialist-onepiece.mjs` from the One Piece wiki — characters from their infoboxes and categories (ranked by subpages and page size, 220 by default; only characters the anime has shown, plus those from chapters it hasn't reached yet), canon Devil Fruits, crews with a Jolly Roger and the wiki's laughter table. Only facts are kept, no article text; re-run it to pick up new characters, bounties and fruits. League rounds: **Classic** (gender, positions, species, resource, range, regions, release year ▲▼), **Ability** (one of the champion's five ability icons, greyscale, turned and blurred, clearing per miss; the ability's key and finally its name as hints), **Splash Art** (a ×3.2 crop of the base splash that pulls back per miss) and **Silhouette**. Data: `src/data/specialist/lol.json`, built by `node scripts/build-specialist-lol.mjs` — champions, abilities, icons and splash arts from Data Dragon; positions, range, resource, class and release date from the League wiki's `Module:ChampionData`; pronouns, species and region from its lore pages. Champions too new for the wiki's data sit out Classic until a later run (`complete: false`). Re-run it after each patch. Marvel rounds: **Classic** on characters (gender, species, team, status, debut film ▲▼, Phase ▲▼, number of films ▲▼), **Film** (a zoomed crop of the poster), **Emoji** (a film told in emojis, hand-written in `scripts/data/mcu-emoji.mjs`) and **Voice Line** (the character speaking in the original English version, 2 → 20 s snippets; clips found by `node scripts/find-marvel-voice-clips.mjs` from YouTube titles, with a reject list for checked mismatches). Data: `src/data/specialist/marvel.json`, built by `node scripts/build-specialist-marvel.mjs` from the MCU wiki — every released film, and the 180 characters with the most films and the biggest articles; pages named after a shared mantle (Captain America, Black Widow…) show the current holder, with the mantle accepted as an answer. Re-run it after each release, and add the new film's emoji line. Genshin rounds: **Classic** (gender, element, weapon, region, rarity, body type, version ▲▼), **Wish Art** (zoomed crop of the wish splash), **Silhouette** and **Constellation** (its name). Data: `src/data/specialist/genshin.json`, built by `node scripts/build-specialist-genshin.mjs` from the Genshin wiki (every playable character but the Traveler); the same data feeds Who's That? Genshin and the Genshin boss (`node scripts/data/genshin-boss.mjs`, then `enrich-bosses.mjs --boss=genshin`). Genshin portraits sit on white: `src/lib/cutout.ts` flood-fills the background away in the browser before they're blacked out. World of Warcraft rounds: **Classic** (gender, race family, faction, class, status), **Art** (a zoomed crop of the character's art), **Silhouette** (a transparent render, blacked out) and **Titles** (their titles, one more per miss; vague ones and ones naming them are left out). Data: `src/data/specialist/wow.json`, built by `node scripts/build-specialist-wow.mjs` from the Warcraft Wiki — only well-known characters from the games: pages Blizzard and the wiki flag as major (Blizzard's *Characters of Warcraft*, Hearthstone heroes, Heroes of the Storm, action figures, faction leaders, city bosses…) ranked by those flags and article size, kept only if they appear in World of Warcraft, with a hand list of iconic ones added (Ner'zhul, Archimonde, the Old Gods…) and of overrated ones left out (Hearthstone originals, minor raid bosses). Facts come from the `{{Npcbox}}` infobox; races are grouped into families (every flight is "Dragon"). Silhouette renders (mostly Warcraft III Reforged) are found among the PNGs named after the character, checked for a transparent border by decoding them in the script, with a reject list for checked mistakes. The same data feeds Who's That? World of Warcraft and the Lich King boss (`node scripts/data/wow-boss.mjs`, then `enrich-bosses.mjs --boss=wow`). Code: `src/specialist/` (data, rounds, games) and `src/pages/Specialist.tsx`.
- **Overwatch and For Honor Specialists**: Overwatch (`src/specialist/simple.ts`) is every hero with voice lines on the Overwatch wiki (`src/data/overwatch-voices.json`, `node scripts/build-overwatch-voices.mjs`): **Voice Line** (one of the wiki's own recordings; the old `/voice-line` page now leads here), **Clue** (the boss's ultimates), **Picture** and **Windows** with the boss's OW2 portraits. For Honor adds **Execution**: one of a hero's executions, the short YouTube video the For Honor wiki shows for it, played in silhouette (black and white, contrast pushed until only the shapes show) — the fighters come out of the shadow with each miss, and the execution's name is a late hint; a video gone from YouTube falls back to the hero's picture in silhouette. Data: `src/data/specialist/forhonor-executions.json` (`{ hero, name, youtubeId, seconds }`, 494 executions for 38 heroes), built by `node scripts/build-forhonor-executions.mjs` from every hero's ExecutionsAndEmotes page (the video ids are in the wiki's file metadata).
- **Guess the Rank** (`/rank`): watch 40 seconds of a ranked game and pick the player's rank from the game's ladder — exact is 100, one rank off is 50. League of Legends, Valorant, Rocket League and Counter-Strike 2 (competitive skill groups, not Premier or FACEIT). Three clips a day per game (different ranks, each as likely as the others whatever YouTube has most of; clips rotate least recently used first), streak and share text, plus endless practice that keeps a saved history so new clips come first. Progress is stored with the Specialist dailies under `rank-<game>:<date>`. Clips play through `src/components/VideoClip.tsx`: no controls, YouTube's title bar (which names the rank) masked, the frame covered whenever it isn't playing, a mid-game start (25–60 % in, past the loading screen where ranks show); a removed video hands over to the next clip of the same rank. Data: `src/data/ranks.json`, built by `node scripts/find-rank-clips.mjs [--game=lol] [--per-rank=5]` from YouTube search results (no API key) — ladders with emblems (CommunityDragon for League, valorant-api.com, the Rocket League and Counter-Strike wikis) and clips whose **title** names exactly one rank: no montages, compilations, guides or reactions, no "Iron to Radiant" climbs or "2 games off Gold", no smurfs "proving a point" in a low lobby, no other modes (ARAM, TFT, Deathmatch, Premier…), ten minutes at least, at most two clips per channel per rank. Titles are trusted, so a reject list holds the clips checked and found wrong. Code: `src/rank/data.ts`, `src/pages/GuessRank.tsx`.
- **Games** (`/games`): the hub for everything beyond the daily, Free Play and the bosses — the nav keeps Daily, Free Play, Boss Battle, Games and Archive, and "Games" stays lit on every game page (`GAME_PATHS` in `src/components/Layout.tsx`). It lists the other dailies (Specialist, Guess the Rank) and the endless arcade games (Who's That?, Higher or Lower, Name Them All, Guess the Year) with the player's progress on each. Arcade best scores live in the store's `bests`, by `"<game>:<mode>"`.
- **Higher or Lower** (`/higher-lower`): two at a time — is the second one higher or lower? A streak until the first miss (ties count as right), best streak per deck. Decks are built from data the app already has (`src/arcade/higherLower.ts`): One Piece bounties and heights, MCU box office (parsed from the wiki's figures) and appearances, League and Genshin release dates, and the release years of every work with a cover.
- **Name Them All** (`/name-them-all`): name every item of a list before the clock runs out (eight seconds a name, 1:30 to 10:00). A name counts as soon as it's spelled exactly (Enter forgives a typo); what was missed is shown at the end. Lists (`src/arcade/lists.ts`) are every boss Knowledge Blitz prompt with six answers or more, retitled ("Name 5 Yordles" → "Yordles"), plus whole rosters: every League champion, Genshin character and MCU film.
- **JLPT** (`/jlpt`): Japanese from N5 to N1. Each level has a Vocabulary and a Kanji deck (`/jlpt/n5-vocab`, `/jlpt/n1-kanji`…) and its grammar list to browse, and twelve **theme** decks mix the words of every level about one thing (animals, food and drink, the body, family and people, nature and weather, time, places, transport, colours, clothes and things, school and work, feelings): a word is in a theme when one of its first three senses is exactly one of the theme's words (`THEMES` in `src/arcade/jlpt.ts`). A word or a kanji is shown with four answers: its meaning, or (40% of the time, for words written in kanji) its reading; the wrong ones come from the same deck. A streak until the first mistake, with 12 seconds a question down to 4; keys 1–4 answer; best streak per deck (`jlpt:<deck>`). Every miss goes on the player's **review list** (`jlptReview` in the store, synced), and any word can be starred onto it or off; **Review** (`/jlpt/review`) quizzes only those, with no clock and no game over: three right in a row and a word is learned and leaves the list, a miss starts it over. Data: `src/data/jlpt.json` (`src/arcade/jlpt.ts`), from Coto Japanese Academy's *JLPT Grammar and Vocab Mega List*, cleaned up: entries without a meaning dropped, repeated ones merged, readings that weren't kana removed and a few mismatched rows fixed (会場/てんいん → 店員).
- **Name Them All, in Japanese**: each JLPT theme is also a Name Them All list (`jlpt-animals`, `jlpt-food`…, franchise JLPT, linked from `/jlpt` too): every word of the theme, named in romaji (long vowels written or not: "toukyou", "tokyo"), in kana or in kanji (`src/lib/romaji.ts`); a word in two levels counts once.
- **Guess the Year** (`/guess-the-year`): five works (all, or one category) with their cover and studio — set the release year on a slider. The exact year scores 100 and each year off costs 10, for a best out of 500 per category.
- **Rail Rush** (`/rail-rush`, prototype): a train on three tracks, faster and faster. Each gate has a character's sign above every track and barricades on one or two of them (usually the train's own, never all three); type the name of a character on a free track to switch to it (exact spelling counts as typed, Enter forgives a typo). A crash costs a wagon, and the run ends with the last one. Pick a line — One Piece, League, Marvel, Genshin, World of Warcraft (the best-known of each Specialist roster), Pokémon or Minecraft (Who's That? rosters) — and a difficulty: Easy (3 wagons), Normal (2) or Hard (1 wagon, faster, blurred signs). Gates appear a few seconds ahead (6 s down to 3.4 on Easy, 4.2 down to 2.3 on Hard), and the speed climbs with every gate. The view is a pseudo-3D track drawn on a 2D canvas, no library (`src/rail/draw.ts`: a raised camera behind the locomotive, parallax hills in the line's colours, scrolling sleepers, gantries, sparks, smoke, speed lines and crash shake); the game loop and HUD are in `src/rail/RailRun.tsx`, the lines in `src/rail/rosters.ts`. Every 10 gates the train brakes into a **station** (platforms, a canopy and the name board: Foosha Village, Demacia, Pallet Town… each line has its own) and the player picks one of three items (`src/rail/items.ts`): **Air bag** (the next crash costs nothing and still counts as a gate passed, points included — an extra wagon only takes the hit; they stack), **Extra wagon** (up to 5), **Brake** (a quarter slower), **Lantern** (first letters on the signs) and **Long view** (gates 1.5 s earlier) — those three last until the next station — or **Switch line**: ride another game from there, and a line not ridden yet in the run adds ×0.5 to the points every gate is worth. The best score (points, so switching lines pays) is kept per starting line and difficulty. At the end of the line, every crash is listed with the characters on the free tracks (and every other name they answer to), and the one the train was under.
- **Who Am I?** (`/who-am-i`): five characters a run (One Piece, League, Marvel, Genshin or Warcraft — the best-known of each Specialist roster); clues come one at a time, vaguest first (gender and origin… down to the first letter and length of the name), and the player names them whenever they like. 100 on the first clue; every extra clue costs 12 and every wrong name 8 (and brings a clue); five wrong names and it's 0. Clues are built from the Specialist data (`src/arcade/whoAmI.ts`).
- **Odd One Out** (`/odd-one-out`): five cards, four of one Connections sub-category and an intruder of the same kind (a character among characters); a round is kept only if no other sub-category would make a different card the odd one. A streak until the first mistake, per theme or all of them (`src/arcade/oddOneOut.ts`).
- **Memory Pairs** (`/memory`): eight pairs face down, two cards turned at a time: a Devil Fruit and its user, a League champion and their ultimate, a Genshin character and their constellation, an MCU character and their actor, a Warcraft character and one of their titles. Points for few flips and little time (`src/arcade/memory.ts`).
- **Franchise Wordle** (`/wordle`): Wordle with names — Pokémon, League champions, Genshin characters, One Piece (short names: Luffy, Zoro…) or Minecraft mobs, 4 to 9 letters once accents, spaces and punctuation are dropped (Kai'Sa → KAISA). Six tries; every guess must be a name of the same length from the same set; green is right in place, yellow elsewhere (as many times as the letter is there). A streak of names found, on an on-screen keyboard or the real one (`src/arcade/wordle.ts`).
- **Quick Sort** (`/quick-sort`): cards one at a time, each to be sent left or right before its bar runs out (3.5 s down to 1.3): melee or ranged champions, Horde or Alliance, 4★ or 5★, alive or dead in the MCU, a bounty under or over 500M, released before or after 2000. Arrow keys, buttons or a swipe; three mistakes end the run (`src/arcade/quickSort.ts`).
- **Six Degrees** (`/six-degrees`): two cards of a Connections theme, three links apart, never linked directly: build a chain where each card shares a sub-category with the last (the link shows once made). Three stars at par with no wrong pick, two for a step over or a couple of slips, one otherwise; give up to see a shortest chain. Five puzzles a run (`src/arcade/sixDegrees.ts`).
- **Expedition** (`/expedition`, MVP): a roguelike made of the other games. Two acts, each a branching map of six rows ending in a guardian; the player picks a path. Rooms: **challenges** (a blurred black-and-white portrait to name, three Higher or Lower calls, an Odd One Out, a Who Am I? within four clues, ten Quick Sort cards, five names of a Name Them All list against the clock), **elites** (the same, harder: more calls, fewer clues, less time — a relic when beaten), **shops** (relics, a heart), **campfires** (a heart or gold) and **gambles** (an elite for a relic). The **boss** is a Boss Battle phase at Medium — a Knowledge Blitz in act 1, a Final Blow in act 2 — and must be beaten (a loss costs two hearts and it comes back). Rooms won pay gold; a lost room costs a heart; no hearts, no expedition. Eight **relics** change the rules (`src/rogue/run.ts`): Hourglass (+5 s on timers), Lantern (first letters), Second wind (first mistake per room forgiven), Loupe (less blur), Vitality (+1 heart), Greed (double gold, −1 heart), Lucky coin (+5 gold a room), Bandage (a heart back after each boss). The run is saved in the store (`rogueRun`); entering a room counts even if the page is left. Score: 10 per room won, plus gold, plus 200 for a full clear. Rooms are in `src/rogue/Rooms.tsx`, the page in `src/pages/Expedition.tsx`.
- **Map Quiz** (`/map-quiz`, test): a place name, a world map — click where it is; inside the place's circle is 100 points, down to 0 at four radii. Eight places a round. Maps live in `src/data/maps.json` (picture, proportions, places as shares of width and height with a radius); Kanto (FireRed/LeafGreen town map) and Runeterra (regions) were placed by eye and are marked `estimated`. **Pin page** `/map-quiz/<map>/edit`: pick a place, click where it is, size its circle, add or remove places; edits are kept in the browser and used by the quiz at once, and "Copy places JSON" gives the list to paste into the data file.
- **Settings**: [`src/data/settings.json`](src/data/settings.json) — `connections.groups` (groups of 4 per hand-made grid; fewer cuts the puzzles down at play time) and `connections.maxMistakes`.
- **Typed answers** go through [`src/utils/textMatcher.ts`](src/utils/textMatcher.ts): case, accents, ligatures and punctuation are ignored, and small typos pass (1 for 3–5 letters, 2 from 6, a swapped pair counts as one).

### Scaling the dataset

`npm run data:seed` runs the whole pipeline (optional imports → French names → wiki check → images → clips → Connections and Boss pictures → validation); see the header of `scripts/seed-database.mjs`. Step by step:

```bash
# 1. Import factual metadata (year, genres, studio, creator, characters, tracklist...)
node scripts/import.mjs anilist "Mob Psycho 100" "Vinland Saga"          # no key
node scripts/import.mjs musicbrainz "Random Access Memories"              # no key
TMDB_API_KEY=... node scripts/import.mjs tmdb --list=films.txt            # one title per line
IGDB_CLIENT_ID=... IGDB_TOKEN=... node scripts/import.mjs igdb "Hades"
node scripts/import.mjs file my-entries.json                              # hand-written batch, any domain

# 2. Write the creative clue fields by hand (emoji, quote, item, location, audio.clue + audio.query, visual)

# 3. Resolve media
node scripts/enrich-media.mjs                    # images from Wikipedia (batched, no key)
YOUTUBE_API_KEY=... node scripts/enrich-media.mjs --no-images   # clip ids from audio.query

# 4. Connections and Boss Battle pictures (Wikipedia, Fandom wikis, League Data Dragon)
node scripts/enrich-connections.mjs
node scripts/enrich-bosses.mjs

# French titles and boss answer spellings (scripts/data/*.mjs)
node scripts/add-french-titles.mjs

# 5. Check
npm run data:validate
```

`enrich-media` looks up `cover.wiki` / `item.wiki` / `location.wiki` with the MediaWiki API (50 titles per request). Item and location clues can instead carry `src` (`fandom:<wiki>:<Title>`, `wp:<Title>` or a URL), or inherit the work's `fandom` wiki, which is then searched by the clue's `name`. Images whose file name looks like a logo, box art, cover or poster — or equal to the work's cover — are rejected so a clue never shows the title. It also and rejects images when a title redirects to a different subject (e.g. "Hyrule" → the franchise page, whose image would give the answer away). Works without `cover.wiki` get one by search — check those. `--force` re-resolves everything; `--dry` writes nothing.

### Media notice

Cover art and many item images are hot-linked from Wikipedia/Wikimedia and are often non-free (used there under fair use). Clips are third-party YouTube uploads played through the official embed. That's fine for a personal fan project; for a public or commercial release, replace them with licensed assets (`image` accepts any URL) and verify each clip.
